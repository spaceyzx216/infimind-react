## 本次修复及真实复验

1. **图文读取**：员工手册专用解析器保留Word表格文字与列分隔，并在图片原有位置插入OCR文本；PDF文字页也提取图片，避免有文字层就跳过同页图片。图片读取失败／无识别文字进入既有未读材料提示，先暂停而非静默跳过；旧解析检查点在新版恢复时重新读取，追问保持原报告原文和位置。
2. **OCR进程隔离**：实际资源下载失败曾使Tesseract抛未捕获错误并退出测试进程。现在OCR在有时限、可取消的子进程中沿用既有识别器，失败返回材料读取提示，不终止API。成功OCR仍会错字，图片例中的“忘打卡”被识别为“乓打卡”，没有用模型偷偷替换原文。OCR引文只代表识别文字，提示及复制报告均保留原件待核对状态。
3. **正常条款与范围**：要求从已提交文字指出具体不利后果，不能假设另一本制度矛盾或系统关闭来制造风险；企业访客／现场管理规则可以是附件，但不能把其对象和时间当成员工考勤。两次正常对照未复现旧的假主体冲突和多余建议；尚不足以证明模型所有输入均稳定。
4. **冲突与归并**：同一分块中的两条不同规则也可冲突，程序验证两处不重叠原文位置；重复或重叠引用不能充作冲突双方。图文复验T11生成两项相关冲突、T15一项合并冲突，均已定位且因OCR保留待核对。模型明确归并且完整保留旧定位区间时允许补充背景引文，修复“增加同一员工背景后反而留下重复冲突”。短文T03最终一项、跨文件T08最终两项。
5. **测试隔离**：首次恢复与未结束测试共享数据库，另一个Worker领取任务，导致混用版本和关闭数据库后的定时器异常；该次不计入通过。脚本增加未结束任务门禁并等待工作结束后关闭；实际尝试恢复旧的未结束运行被门禁拒绝。新评测分组使用各自独立目录，恢复只在原运行结束后执行。

采用结果中35处已匹配引文均通过提取原文切片核对；另有0处无法唯一定位的引文保留限制，没有作为已匹配位置计数。原件准确性仍不能由这些位置匹配证明。

## 2026-10-12补充：后续改进计划（未实现）

以下来自用户本次试用反馈和指标提问，只记录待办，不改写前述2026-10-11结果。

1. **报告文本格式与页面样式**：用户试用反馈输出还需调整。统一问题标题、分析理由、条件、原文和建议的展示层级，检查长文本、列表、换行、原文侧栏及复制报告的格式一致性。具体调整先结合反馈样例确认，不把尚未提供的显示问题写成已定位缺陷；以桌面／窄屏和复制结果验收。
2. **检索与生成分开评测**：先建立人工核对的标注集，记录应关联条款对、参考片段、追问证据和实际候选／送入模型的上下文。关联候选按相关条款对计算Precision／Recall，相关关系包括定义、条件、补充、例外及矛盾；不是只将最终冲突当作相关候选。参考片段和追问检索按各自排序与k计算Precision@k／Recall@k，必要时增加排序指标。生成结果单独标注真阳性、假阳性、漏报、条件保留和建议可执行性，核对引用是否真正支持判断及法律依据。重复运行报告稳定性、耗时和用量。指标定义参考[信息检索评测](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-unranked-retrieval-sets-1.html)和[排序结果评测](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-ranked-retrieval-results-1.html)。
3. **向量检索评估**：员工手册链路尚未接入向量检索。当前逐块检查覆盖所有提取正文，关联候选来自主题规则、章节引用和模型建议；参考资料按共同主题选前2块，追问按词与主题选前4块。先测同义表达、跨主题关联的遗漏，再比较现有方案与语义／混合召回，不用向量Top-k代替正文逐块检查；引入模型、依赖或公共接口前另行说明方案与影响。

当前22/22只是预设观察点的文字／锚文本及引文关系匹配，尚无完整人工金标，不能叫检索召回率或法律准确率。13/13正文与26/26关联候选是运行覆盖，不能证明没有遗漏应关联关系。35处引用切片一致只证明位置匹配，不能证明结论被引用支持。此次参考资料与法规记录基线为空，参考库／法规召回率、检索精确率和生成精确率尚无可报告实测值。此项新增计划未运行新模型或改变现有实现。
