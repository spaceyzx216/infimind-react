# 员工手册虚拟测试用例

本目录现有20组用例（首轮为T01—T19，复验增加T20）。这些材料全部为虚构公司和虚构制度，故意混入矛盾或不合理规定，仅用于软件测试，不能作为企业制度范本。旧知识库手册未参与本次测试，新法务文件尚未收到。

## 怎么使用

在员工手册诊断页上传 `材料/` 中对应文件。T08 和 T09 要把同组文件一起上传；其余按表格单独上传。不要上传本说明、cases.json 或评测结果，它们含预期答案。正常诊断不要求用户选择完整手册或片段，系统自行判断提交范围。

## 预期答案如何确定

跨章节、跨文件矛盾以本次虚构原文和明确的适用条件为依据，不以旧Coze结果作标准。T02等法律方向只作为诊断点预期，最终法条适用、风险级别和修订内容仍需法务验收。不能用“调用成功”“返回七项”代替准确性评测。

- 劳动合同法第4、9、25、39、40条分别涉及制度程序、扣押证件和担保、违约金限制、不同解除情形。公开文本：[上海市政府公布的劳动合同法](https://www.shanghai.gov.cn/rcjygj/20250606/658d064be68c46fc892530a8cde92258.html)。
- 年休假要区分累计工作年限与本单位工作年限，并考虑具体适用条件。公开文本：[职工带薪年休假条例](https://xzfg.moj.gov.cn/front/law/detail?LawID=208&Query=)。
- 扩展领域参考：[劳动法（市场监管总局公开文本）](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_d9aa750028b14b99a776cb93726a360d.html)、[女职工劳动保护特别规定](https://www.shanghai.gov.cn/gwk/search/content/6e04ce0a62054be3a50040f3763fdeb8)、[工伤保险条例（国家行政法规库）](https://xzfg.moj.gov.cn/front/law/detail?LawID=610)。这些来源用于人工确定观察方向，不表示模型已接入逐条核验。
- 私人聊天内容的收集目的、范围和期限是本例明确提出的隐私疑点；没有提供具体法条核验结果时，不能升级为已确认法律结论。
- 本套材料没有设定司法统一认可的旷工天数、迟到次数或损失金额。任何擅自给出的通用阈值都要复查。

## 现有链路的边界

Word、PDF、图片已能提交。本次已补读DOCX内嵌图片和PDF同页图片，失败或未识别文字时暂停，明确选择已读部分后才能继续。复杂表格的行列适用关系、旧DOC转换后的图片、浮动绘图及OCR错字仍需独立核对；支持格式不等于证明原件逐字读取完整。

“具体条文核验尚未完整接入”是指：目前可以核对法规记录名称、版本、状态和来源，尚未逐项核对模型所引具体条文的内容及适用条件。找到《劳动合同法》记录，不等于该问题引用第39条就正确。报告保留待复核状态，程序清单也不意味着已经审查企业的真实讨论、公示或签收证据。

## 复现与评测记录

自动化真实链路命令（从仓库根目录执行；凭据使用获准的本地配置，不提交配置文件）：

```powershell
node --use-env-proxy --env-file=<本地配置路径> server/scripts/test-handbook-live.js --live --cases docs/员工手册诊断测试/cases.json --case T01,T02,T03,T08 --output <仓库外的独立输出目录>
```

不加 `--live` 不调用模型。预期答案不会作为模型输入。真实模型运行会消耗额度，请按编号选择；不传 `--case` 运行整个清单。T11/T15默认只检查解析器，追加 `--diagnose-formats` 可以走上传与诊断链路。本轮脚本使用虚构账号、独立数据库和空法规基线，不加载公司手册或内部知识库。

[首轮评测报告](./首轮评测报告.md)保留原始已知失败、长文性能、修复和限制；[后续复验报告](./复验报告.md)记录此次拆分PR之后的增量。目录不包含模型原始日志、临时数据库、账号会话、个人配置、训练字库或公司材料。Word文档仅将作者及最后修改者元数据统一为Synthetic handbook test，正文和图片部件逐字节核对保持不变；对应指纹见[材料指纹](./材料指纹.json)。
